# Менеджер проектов и заявок Jira

Веб-интерфейс в Битрикс24 для планирования заявок Jira и формирования отчетов. Приложение находится в `forms/project_manager/`.

## Еженедельный отчет в Excel

1. Откройте «Создать отчёт» и выберите тип «Еженедельный».
2. Укажите неделю выполненных задач и неделю запланированных задач.
3. Нажмите «Скачать Excel».
4. При необходимости заполните недостающие сведения в предварительной таблице и нажмите «Сохранить и скачать». Кнопка «Пропустить и скачать» позволяет выгрузить отчет с незаполненными полями.

По умолчанию итоги формируются за предыдущую неделю, план — на текущую. Например, в понедельник 2 ноября 2026 года предлагаются итоги за `2026-W44` и план на `2026-W45`. В заголовках Excel показывается диапазон с понедельника по пятницу. Недели хранятся в формате ISO: год недели и ее номер; на границе года год недели может отличаться от календарного года даты.

### Общие фильтры

К еженедельному отчету применяются выбранное направление ODS/SSIS, фильтр статусов Jira и фильтр тегов. При выборе нескольких тегов у заявки должны быть все выбранные теги. Текстовый поиск на состав отчета не влияет.

Отчет формируется из загруженного списка заявок. Заявки, загруженные только для состава локальных проектов (`projectOnly`), в еженедельный отчет не включаются.

### Состав разделов

| Раздел | Условия включения заявки |
| --- | --- |
| «Итоги за неделю» | Поле «Неделя выполнения» (`completedWeek`) совпадает с выбранной неделей итогов. Текущая колонка заявки не является условием отбора. |
| «План на неделю» | Заявка находится в колонке «Эта неделя» или «Следующая неделя», и ее поле «Плановая неделя» (`plannedWeek`) совпадает с выбранной неделей плана **либо** в планируемых действиях есть запись за эту неделю. |
| «Список задач (задачи не вошедшие в списки выше)» | Заявка не попала ни в итоги, ни в план, ее сложность не равна «Низкая», она не находится в колонке «Выполнено» и ее статус Jira не распознан приложением как завершенный. |

Одна заявка может одновременно попасть в итоги и план, если удовлетворяет обоим условиям. В таком случае в «Прочие» она не дублируется.

### Какие сведения выводятся

Для заявок средней, высокой и максимальной сложности в итогах и плане создаются отдельные строки:

- номер заявки и дата создания;
- ИС: компоненты Jira для ODS, тип запроса для SSIS;
- краткое описание из карточки;
- планируемые действия и факты за неделю соответствующего раздела.

В итогах используются записи плана и факта за неделю итогов, в плане — за неделю плана. Несколько записей за одну неделю соединяются переносами строк. Дата создания записи не определяет ее отчетную неделю: используется неделя, указанная у самой записи. Описание из Jira добавляется как примечание к ячейке краткого описания.

Заявки низкой сложности объединяются в строку техподдержки внутри соответствующего раздела. В строке перечисляются номера заявок и проекты, в итогах дополнительно выводится количество выполненных заявок.

В «Прочих» поле «Статус задачи» содержит текст последней записи факта в истории, без ограничения выбранной неделей. К краткому описанию добавляются названия и годы связанных локальных проектов. Поля ожидаемой даты выполнения и комментария сейчас остаются пустыми.

### Проверка перед скачиванием

Для заявок средней, высокой и максимальной сложности приложение предлагает заполнить:

- в итогах — отсутствующие краткое описание и факт за выбранную неделю итогов;
- в плане — отсутствующее планируемое действие за выбранную неделю плана.

Отсутствие текста действия само по себе не исключает заявку из плана, если совпадает `plannedWeek` и подходит колонка. В этом случае действие можно заполнить перед выгрузкой.

### Почему заявка оказалась в «Прочих»

Проверьте колонку, выбранную неделю плана, поле «Плановая неделя» и недели записей в блоке «Планируемые действия». Наличие факта за текущую неделю само по себе не включает заявку в план.

Например, у ODS-6847 может быть указана плановая неделя `2026-W44`, но добавлено действие за `2026-W45`. Если заявка находится в колонке «Эта неделя» или «Следующая неделя», она включается в план на W45 по записи действия. В прежней реализации проверялось только поле `plannedWeek`, поэтому такая заявка попадала в «Прочие». Для нового поведения на сервере должна быть установлена версия с исправлением отбора по неделе действия; после обновления следует перезагрузить страницу и сформировать отчет заново.

Если заявка отсутствует во всех разделах, также проверьте фильтры направления, статуса и тегов, наличие заявки в загруженном списке и ее сложность: низкая сложность в итогах и плане представлена общей строкой техподдержки.

## Ежемесячный отчет

1. В окне «Создать отчёт» выберите тип «Ежемесячный».
2. Выберите месяц и откройте страницу отчета.
3. Нажмите «Сформировать». Результат можно скопировать целиком.

Для этого отчета сервер отдельно запрашивает заявки, назначенные текущему пользователю Битрикс24 в Jira, с датой решения (`resolved`) от первого дня выбранного месяца включительно до первого дня следующего месяца исключительно. На странице остаются заявки средней, высокой и максимальной сложности с учетом выбранного направления ODS/SSIS. Фильтры статусов и тегов еженедельного отчета здесь не применяются.

Каждая строка содержит номер заявки, краткое описание (или название из Jira, если краткое описание не заполнено) и названия связанных локальных проектов. Подсказка у номера показывает описание Jira и факты из истории без ограничения месяцем. Ежемесячный отчет открывается на странице приложения, а не выгружается в Excel.

## Где описаны правила в коде

- `forms/project_manager/app.js`: отбор заявок, подготовка строк и проверка заполненности еженедельного отчета, отображение ежемесячного отчета.
- `forms/project_manager/api/report.php`: проверка входных данных и вызов экспорта Excel.
- `forms/project_manager/src/ReportExporter.php`: оформление Excel.
- `forms/project_manager/api/issues.php`: запрос заявок Jira для ежемесячного отчета.
- `forms/project_manager/user_guide.html`: встроенная инструкция пользователя.

Проверка отбора заявок еженедельного отчета:

```sh
node --test forms/project_manager/tests/weekly-report.test.cjs
```
