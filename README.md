# Bitrix24 Project Manager

Интерактивный прототип рабочего пространства для управления заявками Jira в Битрикс24.

## Запуск

Создайте конфигурацию интеграции (файл с секретами исключён из Git):

```bash
cp forms/project_manager/.env.example forms/project_manager/.env
```

Укажите в `.env` логин и пароль Jira, затем запустите PHP-сервер:

```bash
php -S 127.0.0.1:8080
```

После этого интерфейс доступен по адресу `http://localhost:8080/forms/project_manager/`.

## Jira

Backend обращается к Jira Server API v2 с Basic Auth. Секреты используются только на сервере и не попадают в браузер. По умолчанию загружаются:

- открытые задачи текущего пользователя проекта ODS;
- открытые заявки SSIS для корпоративного портала по предоставленному JQL-фильтру.

Оба JQL-запроса можно переопределить переменными `JIRA_ODS_JQL` и `JIRA_SSIS_JQL`.
